## 2024-05-18 - Predictable Temp File Vulnerability (LPE) in PrivilegeManager
**Vulnerability:** `PrivilegeManager.swift` used a predictable, world-writable temporary file path (`/tmp/pkill_sudoers_\(PID)`) to store sudoers configuration before moving it with elevated privileges via an AppleScript prompt. This created a TOCTOU race condition where a malicious process could overwrite the file while waiting for the user to authenticate the prompt, resulting in Local Privilege Escalation (LPE). Additionally, the destination was incorrect (`/etc/sudoers.d/pkill` instead of `milo`).
**Learning:** Never use predictable filenames in world-writable directories like `/tmp/` when the file will subsequently be used in a privileged operation, as it allows attackers to inject their own contents during the execution window.
**Prevention:** Use `FileManager.default.temporaryDirectory` combined with a cryptographically secure random identifier (like `UUID().uuidString`) to ensure the file path is unique, unpredictable, and located in a directory with proper permissions for the user.
