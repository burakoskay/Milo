# Security Policy

## Supported Versions

Milo is currently pre-release software. Security fixes are applied to the latest `main` branch and to any tagged release publicly distributed by monomacaw.

| Version | Supported |
| ------- | --------- |
| Latest public release | Yes |
| Older releases | No, unless explicitly stated in release notes |
| Unofficial builds, forks, or modified binaries | No |

## Reporting a Vulnerability

Milo is currently pre-release and this repository is private.

For now, report vulnerabilities directly to the repository maintainer through the verified GitHub account associated with this repository.

Before public distribution, monomacaw will provide a dedicated security contact at:

security@monomacaw.com

Do not open public issues for vulnerabilities involving licensing, payment webhooks, Supabase policies, privilege escalation, process termination, telemetry signatures, secrets, or binary hardening.

## Response Targets

We aim to acknowledge valid reports within 72 hours.

Critical vulnerabilities involving payment, licensing, privilege escalation, secret exposure, or signed telemetry distribution receive priority handling.
